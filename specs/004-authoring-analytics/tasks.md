# Tasks: Walkthrough Authoring and Usage Analytics

**Input**: [spec.md](./spec.md), [plan.md](./plan.md). No other design documents: types live in `plan.md` and in code.
**Base branch**: `dev`. Cut each slice from `dev`; merge with `--ff-only` into `dev`. `main` is ignored.
**Format**: `- [ ] T### [TIER] [P?] Description (paths) - acceptance`. `[P]` = can run in parallel with the other `[P]` tasks of the same slice. Task ids start at T401 so they never collide with Features 001-003.
**Tiers (Constitution XIX)**: every open task is `[REQUIRED]`, `[OPTIONAL]` or `[FUTURE]`. Only REQUIRED tasks gate Feature 004. OPTIONAL is promoted only if a demo scenario needs it.

**Gate reporting**: every gate command is reported as one line (command, PASS or FAIL, log path); on failure, the single most relevant error line.
